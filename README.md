# nuh-omop-pipeline
An OMOP CDM 5.4 pipeline for the NUH oncology research data, built with [dbt](https://docs.getdbt.com/) and [DuckDB](https://duckdb.org/).

See [the plan](docs/plan.md) for the design and the order of the work, and [the issues](https://github.com/Health-Informatics-UoN/nuh-omop-pipeline/issues) for the work itself.
